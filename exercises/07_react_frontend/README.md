# 07 React - Frontend

## Setup Required

- Node 24 + pnpm, `pnpm install` once before the interview
- IDE
- Nothing else, the mock API is dependency-free Node

## Problem

- Empty Vite + React + TypeScript project, mock backend in `mock-api/`
- Build a Todo frontend (see `INSTRUCTIONS.md`, UI sketches in `docs/`)

## Evaluation

- Component boundaries / state / data fetching
- The scope is deliberately larger than 60 minutes: does the candidate say so,
  and what do they cut?
